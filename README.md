# Object Detection using TensorFlow

## Project Overview
This project demonstrates object detection using TensorFlow and Python.

## Technologies Used
- Python
- TensorFlow
- NumPy
- Pandas
- OpenCV
- Matplotlib

## Project Workflow
1. Import libraries
2. Load the required data
3. Preprocess the data
4. Build the object detection model
5. Train/test the model
6. Detect objects
7. Visualize the results

## Requirements
Install the required libraries using:

pip install -r requirements.txt

## How to Run
Open object_detection.ipynb in Google Colab or Jupyter Notebook and run the cells sequentially.
